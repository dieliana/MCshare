# MC Modpack Hub・我的世界整合包资源分享站

纯 PHP + MySQL 实现的整合包分享站，带管理后台与 Web 安装向导，可直接部署到任意支持 PHP 的服务器（宝塔、虚拟主机、VPS）。

## 功能一览



* **前台**：整合包卡片列表（封面、名称、简介、标签、MC 版本、**模组加载器**、浏览 / 下载量）；按分类 / 标签 / **加载器**筛选、关键词搜索、最新 / 热门 / 下载量排序、分页；整合包详情页（大图、完整介绍、**作者社交链接**（GitHub/B 站 / 抖音 / 个人网站）、下载按钮、相关推荐）；下载次数自动统计；多套主题可切换（🎨 按钮 + 后台设置）；Logo 与浏览器标签图标可自定义；主页可自动刷新；前台「发布整合包」页——作者 / 管理员提交后直接发布，普通用户提交进入后台审核；「我的发布」管理自己的整合包（编辑 / 删除，作者可在详情页置顶 / 删除自己整合包下的评论）。

* **管理后台**：数据看板；整合包增删改查（封面上传或**从图库选用**、**模组加载器**、作者社交链接、标签多选、分类、发布 / 草稿状态）；分类管理；标签管理；**图库管理**（上传 / 复制路径 / 删除 / 选用图片）；站点设置（名称、描述、公告、页脚、主题、Logo、标签图标、自动刷新间隔）；**审核中心**（整合包审核：通过 / 驳回并填原因；作者申请审核：通过 / 拒绝）；**用户禁言**（禁言后仍可登录，但不能评论与发布，可解禁）。

* **Web 安装向导**：环境检测 → 数据库配置（地址 / 端口 / 库名 / 账号 / 密码，可自动建库）→ 站点信息与管理员 → 执行安装（建表、写入配置、创建管理员）。

## 部署步骤（Apache / 宝塔）



1. 把整个目录上传到站点根目录（如 `/www/wwwroot/你的域名/`）。

2. 确保 `uploads/` 目录可写（PHP 运行用户有写权限）。

3. 浏览器访问 `http://你的域名/install.php`，按向导完成：

* 环境检测（PHP ≥ 8.0，需 `pdo_mysql`、`mbstring` 扩展）

* 填写数据库地址 / 端口 / 库名 / 账号 / 密码（可勾选自动建库）

* 填写站点名称和管理员账号密码

1. 安装完成后自动生成 `config.php` 与 `install.lock`。

2. 用 `http://你的域名/admin/login.php` 登录后台，开始添加整合包。

3. （可选）安装完成后删除 `install.lock` 以外的临时说明，并妥善保管后台密码。

## Nginx 部署注意事项

Nginx 不支持 `.htaccess`，请在站点配置中补充以下安全规则：



```
# 禁止直接访问数据库配置
location ~ ^/config\.php$ { deny all; }
location ~ ^/includes/ { deny all; }
location ~ ^/schema\.sql$ { deny all; }

# 上传目录禁止执行 PHP
location ~ ^/uploads/.*\.(php|php5|phtml|phar)$ { deny all; }

# 禁止目录列举
autoindex off;
```

另外确保 PHP-FPM 站点把 `index.php` 设为默认索引。

## 技术要点



* **安全**：PDO 预处理防 SQL 注入；密码使用 `password_hash`；后台登录态基于 Session + CSRF 令牌；封面上传校验真实图片类型并重命名、禁止 PHP 执行；`config.php` 与 `includes/` 禁止 Web 直访。

* **数据**：整包内容由后台录入、前台读取，持久化存储于 MySQL。

## 后台默认入口

安装完成后访问 `admin/login.php`，使用安装时设置的管理员账号登录。

## 用户系统（评论 / 点赞 / 收藏 / 用户中心）



* **注册**：前台顶部「注册」，需填用户名、邮箱、密码 + 邮箱验证码 + 算术验证码。邮箱验证码经 SMTP 发送，需先在后台「站点设置」配置 SMTP。

* **登录**：用户名或邮箱 + 密码 + 算术验证码。

* **用户中心**（`profile.php`）：改昵称、上传头像、改密码，查看我的收藏 / 评论 / 互动。

* **评论**：详情页评论区，登录后 2-500 字；后台「评论管理」可隐藏 / 显示 / 删除。

* **点赞 / 收藏**：详情页一键操作，未登录自动跳登录。

* **后台**：`admin/users.php` 用户管理（搜索、封禁 / 解封、设为 / 取消管理员）；`admin/comments.php` 评论管理；`admin/mail.php` 邮件发送（全部 / 正常 / 手动邮箱批量群发）。

### 作者 / 审核 / 站内信 / 禁言

* **作者申请**：前台「用户中心 → 作者身份」填写申请理由提交，后台「审核中心 → 作者申请」通过 / 拒绝；通过后角色变为「作者」，可直接发布整合包。

* **前台发布**：`/submit` 发布整合包（普通用户提交进入待审核）；`/my-modpacks` 我的发布（编辑 / 删除）。

* **后台审核**：`admin/verify.php` 审核中心，审核待发布整合包（通过 / 驳回并填原因，审核结果通过站内信通知发布者）。

* **站内信**：评论回复 / 评论被点赞 / 评论被置顶 / 整合包更新 / 系统消息都会发站内信；顶部铃铛查看，支持全部已读 / 单条已读 / 删除。

* **评论管理**：作者可在自己整合包下置顶 / 删除评论；管理员在后台可置顶 / 删除任意评论。

* **禁言（可填原因 + 可追加）**：后台「用户管理」、评论管理以及前台详情页的管理员，均可在禁言时填写原因，并可选「追加禁言」在原有到期时间上延长；通知（站内信 + 邮件）会带上禁言原因；到期自动解除。被禁言用户在「用户中心」可看到禁言横幅（含原因）并提交申诉；后台新增「申诉管理」页，通过即解除禁言、驳回可填写回复，结果经站内信 + 邮件回执。

* **发布（原创 / 转载）与下载（多链接 / 服务器上传）**：前台 `/submit` 与后台新增整合包均可选择「原创 / 转载」并填写转载来源（前台详情页显示标记）。下载支持添加多个下载链接（详情页按下载源分别展示并单独统计）。后台新增整合包时还可直接将整合包文件上传到服务器（`uploads/modpacks/`，支持 zip/rar/7z/jar/mrpack/json/txt，≤500MB），访客通过下载按钮直接下载服务器上的文件。

### SMTP 邮箱配置（注册验证码 / 批量发邮件必需）

**安装向导第 3 步**已提供「SMTP 邮件配置（可选，可跳过）」区块：勾选启用后填写服务器、端口、账号、授权码、发件人与加密方式，安装即自动写入配置。

也可在安装后到**后台「站点设置 → SMTP 邮箱」**配置：服务器（如 [smtp.qq.com](https://smtp.qq.com)）、端口（587 用 STARTTLS、465 用 SSL）、账号（邮箱）、密码 / 授权码、发件人地址与名称、加密方式。保存后到「邮件发送」页发一封测试邮件验证。未配置则注册的邮箱验证码与批量邮件不可用。

## 伪静态（友好 URL）

前台已改为伪静态地址，不再显示 `.php` 和查询参数：



* 首页 `/`

* 详情 `/modpack/整合包别名`

* 下载 `/download/整合包别名`（多下载源：`/download/整合包别名/下载项ID`）

* 登录 / 注册 / 退出 / 用户中心：`/login` `/register` `/logout` `/profile`

> 后台管理端保留真实路径（
>
> `/admin/...`
>
> ），仅前台对外美化。

### Apache 环境（含宝塔・Apache）

已随项目附带 `.htaccess`，直接上传到站点根目录即可，无需额外操作（需服务器开启 mod\_rewrite，宝塔默认开启）。

### Nginx 环境（含宝塔・Nginx）

Nginx 不解析 `.htaccess`，请在「站点 → 伪静态」中粘贴以下规则（或写入站点配置文件 `server{}` 内）：



```
location / {
    if (!-e $request_filename) {
        rewrite ^/modpack/([^/]+)/?$ /detail.php?slug=$1 last;
        rewrite ^/download/([^/]+)/?$ /download.php?slug=$1 last;
        rewrite ^/(login|register|logout|profile)/?$ /$1.php last;
        rewrite ^/submit/?$ /submit.php last;
        rewrite ^/my-modpacks/?$ /my-modpacks.php last;
        rewrite ^/messages/?$ /messages.php last;
        rewrite ^/index\.php$ / permanent;
    }
}
```

保存并重载 Nginx 后即可生效。

### 本地 PHP 内置服务器（无 Apache / Nginx）

用 `php -S` 启动时 `.htaccess` 不生效，直接访问 `/submit`、`/my-modpacks`、`/messages`、`/modpack/x` 等会 404。请在项目根目录执行：

```
php -S 127.0.0.1:8080 router.php
```

随后访问 `http://127.0.0.1:8080/`。项目内置的 `router.php` 会把所有伪静态地址正确路由到对应 PHP 文件（`/modpack/x`、`/download/x`、`/login`、`/register`、`/logout`、`/profile`、`/submit`、`/my-modpacks`、`/messages`，以及静态资源与 `admin/` 后台）。

> 若用宝塔 / XAMPP 等 **Apache** 环境仍 404：请确认已启用 `mod_rewrite`，且站点目录「伪静态 / AllowOverride All」已开启（宝塔默认开启）。
> 若用 **Nginx**：`.htaccess` 不生效，请按上文「Nginx 环境」的规则补充 `submit / my-modpacks / messages` 三条 rewrite。
### 每日总结定时任务（站内信 + 邮件）

每天凌晨 4 点自动汇总过去 24 小时全站动态（新增整合包 / 新增评论 / 你的整合包新评论 / 你的评论新回复），通过站内信和邮件推送给每位用户。

- **Linux / 宝塔计划任务**（宝塔 → 计划任务 → Shell 脚本）：
  ```
  0 4 * * * php /网站绝对路径/cron_daily.php >> /网站绝对路径/cron_daily.log 2>&1
  ```
- **Windows 计划任务**：创建任务 → 触发器每天 04:00 → 操作：程序 `php.exe`，参数 `D:\Desktop\MCshare\cron_daily.php`。
- 未配置 SMTP 时只发站内信；配置后自动同步发美化邮件。
- 命令行自测：`php cron_daily.php`
## 维护模式

后台「站点设置 → 维护模式」开启后，前台访客访问将显示维护提示页（HTTP 503），管理员不受影响（前台 admin 账号、后台已登录管理员均可正常访问预览）。可自定义维护提示语，适合升级、维护期间使用。
